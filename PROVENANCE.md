# Repository Provenance

This repository is derived from the original `Tenodex/IRRS` repository:

https://github.com/Tenodex/IRRS

The original repository was used as the publication-linked distribution of the Incident Response Readiness Score (IRRS) toolkit associated with:

> Abid, M. et al. (2026). *Understanding Incident Response Readiness Through Human and System Telemetry*. Information and Computer Security.

The repository history was imported into `MAbidResearch/IRRS` to preserve the revision history of the research artefacts while allowing subsequent documentation, reproducibility, versioning, and artefact-governance updates to be maintained independently.

## Imported Baseline

The imported baseline corresponds to commit:

`1b7053c5c4c9f81440495964c6f87cdbcc3595be`

This commit represents the state of the imported `Tenodex/IRRS` repository before changes were made within `MAbidResearch/IRRS`.

## Repository Relationship

The two repositories serve different purposes:

- `Tenodex/IRRS` remains the publication-linked distribution associated with the earlier research outputs.
- `MAbidResearch/IRRS` is maintained as the current research distribution and will contain the frozen version used for citation and reproducibility.

The original repository is not replaced or modified by this repository.

## Version of Record

A frozen release of this repository will be created once the artefact set is finalised.

The planned release tag is:

`v1.0-thesis`

The release commit, release date, licence, file manifest, and cryptographic hashes will be recorded when the frozen release is created.

Until that release exists, the `main` branch should be regarded as the current working distribution rather than an immutable version of record.
